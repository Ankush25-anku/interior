# Transition System

The website should feel like one continuous cinematic interior experience.

Rules:

## Hero → About

When leaving Hero:

- 3D room slowly zooms out
- camera moves backward
- background color blends into About section
- floating elements dissolve

## About → Services

Create transition:

- typography expands
- image morph effect
- background texture changes

## Services → Gallery

Cards should transition into project images.

Use:

GSAP ScrollTrigger

## Gallery → Testimonials

Image layers fade into testimonial cards.

## Overall

Avoid disconnected sections.

Create a storytelling experience.
